# Changelog

## 1.1.0

- Ported five old pizzerias: Discount Diner, Fredbear's, Jeff's Pizza, FNAF 1, FNAF 2.
- Added natural worldgen: five pizzerias, FNAF 4 booth, large tent, carnival.
- Added custom structure type with fixed rotation and chunk-safe placement.
- Rebuilt big doors, 3x3 entrance, doors, signs, lockers, and block entities.
- Added terminal shop entries: five deeds and 40+ FNAFMW blocks.
- Added loot: chest/barrel loot table and locker loot (money, cobwebs, rares).
- Added `/pizzeria loot` to fill empty containers in loaded chunks.
- Added NBT normalization/validation tools.
- English and Russian localization.
